### 🦿 AI-ENABLED UGV HEXAPOD

**Six Legs · 18 DOF · ROS 2 · ESP32 · Computer Vision**

I'm building an **18-DOF hexapod UGV** as my final-year robotics project,<br>
taking it from mechanical design all the way to embedded control.

<br>

<table>
<tr>
<td align="center" width="190">

**🛠️ DESIGN**

Fusion 360<br>↓<br>URDF / Xacro

</td>
<td align="center"><b>→</b></td>
<td align="center" width="190">

**🧪 SIMULATE**

ROS 2<br>↓<br>Gazebo + RViz2

</td>
<td align="center"><b>→</b></td>
<td align="center" width="190">

**📐 CONTROL**

Kinematics + Gait<br>↓<br>ESP32 Servo Control

</td>
<td align="center"><b>→</b></td>
<td align="center" width="190">

**🦿 PHYSICAL**

18-DOF Hexapod<br>↓<br>Vision + Interaction

</td>
</tr>
</table>

<br>

<details>
<summary><b>▸ CLICK TO EXPAND — PIPELINE BREAKDOWN</b></summary>

<br>

| STAGE | WHAT HAPPENS | TOOLS |
|:---:|:---:|:---:|
| **DESIGN** | Legs, body and joints designed for 3D printing | `Fusion 360` `3D Printing` |
| **MODEL** | Robot description exported for simulation | `URDF/Xacro` |
| **SIMULATE** | Kinematics and gaits tested virtually first | `ROS 2` `Gazebo` `RViz2` |
| **CONTROL** | Inverse kinematics and gait drive all 18 joints | `Python` `IK` |
| **EMBEDDED** | ESP32 handles servo signals and communication | `ESP32` `Servo Control` |
| **PERCEIVE** | Camera-based vision for awareness | `Computer Vision` |

</details>
