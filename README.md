## About Me

I am a Computer Science student specializing in Artificial Intelligence, currently focused on **robotics and intelligent embedded systems**.

My main interest is building robotic systems from the ground up — from mechanical design and CAD modelling to kinematics, simulation, embedded control, computer vision, and software integration.

Currently, I am working on an **18-DOF hexapod UGV**, where I am exploring:

* Mechanical design and CAD using Fusion 360
* Inverse kinematics and gait generation
* ROS 2, URDF/Xacro and robot simulation
* Embedded systems and ESP32
* Computer vision and object tracking
* AI-assisted human-robot interaction
* Web-based robot control interfaces

Alongside robotics, I have experience in **AI/ML, full-stack web development, and graphic design**, which allows me to approach projects from both the engineering and creative sides.

I am particularly interested in the intersection of:

**Robotics + AI + Embedded Systems + Software + Design**

## Featured Project

### AI-Enabled UGV Hexapod

An 18-DOF six-legged UGV that I am developing as my final-year robotics project.

The project combines:

* Mechanical CAD design
* 18-DOF legged locomotion
* Inverse kinematics
* Gait generation
* ROS 2
* URDF/Xacro
* Gazebo & RViz2
* ESP32-based embedded control
* FPV camera system
* Computer vision
* Web-based HMI
* AI-assisted voice interaction

The development workflow is designed to move from **CAD → robot description → ROS 2 → simulation → embedded control → physical prototype**.

I am documenting the process as I build it, including the problems, experiments, measurements, mistakes, and things I learn along the way.
