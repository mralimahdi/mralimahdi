# 🦿 AI-ENABLED UGV HEXAPOD

### `18-DOF` • `SIX LEGS` • `ROS 2` • `COMPUTER VISION` • `EMBEDDED CONTROL`

I am currently building an **18-degree-of-freedom hexapod UGV** as my final-year robotics project.

The development is being approached as a complete engineering pipeline:

<br>

```text
MECHANICAL DESIGN
       ↓
FUSION 360
       ↓
URDF / XACRO
       ↓
ROS 2
       ↓
GAZEBO + RVIZ2
       ↓
KINEMATICS + GAIT
       ↓
ESP32 EMBEDDED CONTROL
       ↓
PHYSICAL ROBOT
       ↓
VISION + HUMAN-ROBOT INTERACTION
```

<br>

### Core Areas

`CAD` • `Inverse Kinematics` • `Gait Generation` • `ROS 2`
`URDF/Xacro` • `Gazebo` • `RViz2` • `ESP32` • `Servo Control`
`Computer Vision` • `Web Control` • `Human-Robot Interaction`

The project combines mechanical design, locomotion, simulation, embedded control,
computer vision, web-based control, and AI-assisted voice interaction.
